Relay Architecture & Governance Model

Relay is an open-source, local-first security gateway designed to sit between autonomous AI agents and sensitive target infrastructure (databases, APIs, filesystems, and Model Context Protocol servers).

Core Architectural Invariant: The LLM is never the security boundary. Relay treats all agent prompts and tool arguments as untrusted input and subjects every action to deterministic evaluation.

1. The Four-Layer Security Architecture

1. Policy Decision Point (PDP)

Evaluates every proposed tool call against Cedar policies compiled into the binary. Strict default-deny rules prevent unauthorized SQL mutations, directory traversal, or egress pings.

2. Credential Broker

Injects scoped, short-lived tokens into mediated network or connector requests right before wire dispatch. The agent never observes production credentials in prompt memory or context windows.

3. Interactive Approval Gateway

High-risk actions require real-time human authorization via /dev/tty out-of-band prompts with nonce validation, completely isolated from web or agent spoofing.

4. Tamper-Evident Ledger

Emits in-toto DSSE action receipts signed by an Ed25519 local key, continuously linked into an append-only SQLite hash-chained ledger for zero-knowledge auditing.

2. Supported Connectors

Connector Governance & Boundary Credential Handling
Filesystem (fs) Canonical path resolution, directory jail containment, strict .env block OS filesystem permissions
PostgreSQL (pg) AST query inspection, read-only enforcement, table access boundary Vaulted connection string via OS Keyring
GitHub (gh) Repository-scoped REST actions, PR/Issue/Commit bound mediation Fine-grained Personal Access Token (PAT)
External MCP Servers Stdio / Unix socket proxying, anti-SSRF IP filtering, loopback mediation Mediated bearer tokens and TLS mutual auth

3. Local Security Console

Launched via relay ui, the local security console runs strictly on 127.0.0.1. It gives security engineers and developers comprehensive visibility into policy enforcement, action receipts, connector health, and cryptographic verification without transmitting any data over the internet.
