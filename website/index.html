Formally Verified Policies

Enforce Cedar default-deny rules before any tool invocation. Restrict databases to read-only queries, bound filesystem access, and forbid dangerous shell execution.

Ambient Credential Vaulting

Keep production API keys, GitHub tokens, and database passwords out of LLM prompts and subprocess environments. Credentials stay safely in your OS keyring.

Cryptographic Action Receipts

Every governed action emits an Ed25519 DSSE-signed in-toto statement appended to an immutable, hash-chained SQLite ledger. Verifiable offline anytime.

Step-Up Human Approvals

Sensitive actions require human confirmation via out-of-band /dev/tty prompts with anti-forgery tokens, preventing prompt injection bypasses.

Zero Telemetry & Sovereignty

Relay never uploads your prompts, tool arguments, database queries, or credentials to any cloud server. No product telemetry, no forced accounts.

Local Security Console

Inspect security posture, explore action receipts, validate Cedar policies, and verify ledger cryptographic chains via a loopback-only zero-trust web console.
