Install Relay v0.1.0

Relay is distributed as a single static binary for Linux and macOS. Release packages are signed using our offline Ed25519 release authority.

Quick Install (Shell)

curl -fsSL https://relay.dev/install.sh | sh

Homebrew (macOS & Linux)

brew install relay-security/tap/relay

Build from Source (Rust 1.78+)

git clone https://github.com/relay-security/relay.git && cd relay && cargo build --release

Verify Binary Cryptographic Signature

Every release includes an authentic SHA-256 checksum manifest signed by Relay's release key:

relay verify-release --manifest SHA256SUMS.sig

Getting Started in 60 Seconds

  1. Initialize local workspace: relay init
  2. Run system diagnostics: relay doctor
  3. Start the local security console: relay ui
