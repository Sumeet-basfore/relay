## 1. Foundational Trust Boundary

Relay establishes an explicit, local-first policy-enforced execution boundary between AI agent clients and sensitive tools:

```text
Untrusted AI Agent (Claude / Cursor / Client Stdio)
       │ (JSON-RPC 2.0 frames ≤ 16MB)
       ▼
┌─────────────────────────────────────────────────────────────┐
│ Relay Gateway Security Boundary                             │
│  - RFC 8785 JSON Canonicalization (SI-002)                  │
│  - Fail-Closed Cedar Policy Authorization Engine (SI-004)   │
│  - Out-of-Band Interactive Human Approval (/dev/tty) (SI-018)│
│  - Ephemeral JIT Credential Leasing & Zeroize (SI-006, 008) │

       │ Native Dispatch                              │ Subprocess Dispatch
```

## 2. Invariant Baseline (SI-001 to SI-024)

Relay v0.1.0 unconditionally satisfies all 24 formal Security Invariants specified in `docs/release/GA004-invariant-registry.md`:

1. **SI-001:** Zero Target Credentials in Agent Context/Memory
2. **SI-002:** Deterministic Action Hashing (RFC 8785 JCS)
3. **SI-003:** Canonical Tool Schema & Identity Pinning
4. **SI-004:** Fail-Closed Cedar Policy Authorization
5. **SI-005:** Approval Binding & Expiration Invariant
6. **SI-006:** Ephemeral JIT Credential Leasing
7. **SI-007:** Zero Ambient Credentials to Child Subprocesses
8. **SI-008:** In-Memory Secret Zeroization (`zeroize::Zeroize`)
9. **SI-009:** DSSE RFC 9598 Cryptographic Envelope Signing
10. **SI-010:** Immutable Policy Set Digest Evidence
11. **SI-011:** SQLite Hash-Chain Ledger Integrity
12. **SI-012:** Database Write-Once Immutability Triggers
13. **SI-013:** Verification Self-Consistency (`relay verify`)
14. **SI-014:** Restrictive Filesystem Permissions (0600/0700)
15. **SI-015:** Explicit Uncertainty on Ambiguous Mutations
16. **SI-016:** Replay Rejection on Historical Receipts/Nonces
17. **SI-017:** Secret Scrubbing in Receipts and Diagnostic Logs
18. **SI-018:** Out-of-Band Interactive Human Approval (`/dev/tty`)
19. **SI-019:** External MCP Egress Destination Authorization
20. **SI-020:** Ephemeral Proxy Session Token Binding (30s TTL)
21. **SI-021:** Vaulted Upstream Credential Injection
22. **SI-022:** Anti-SSRF & Cloud Metadata Pre-DNS Blocking
23. **SI-023:** Linux Unprivileged Network Namespace Isolation
24. **SI-024:** Fail-Closed Platform Sandbox Initialization
