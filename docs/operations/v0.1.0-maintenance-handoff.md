cargo clippy --workspace --all-targets --all-features -- -D warnings

## 3. Security Maintenance & Triage

1. **Vulnerability Disclosure:** Inbound vulnerability reports arriving at `security@relay.dev` must be triaged according to `docs/security/incident-response.md`.
2. **Patch Criteria:** Only security invariant repairs, critical CVE fixes, and platform installation regressions qualify for `v0.1.Z` patch releases.
3. **Feature Freezing:** No new connectors, breaking policy changes, or protocol expansions may be added to `v0.1.x`. All new features belong in `docs/roadmap/v0.2.md`.
