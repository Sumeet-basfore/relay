# Relay v0.2 Roadmap & Post-GA Planning

**Status:** Draft / Planned Features  
**Target Window:** Q4 2026  
**Prerequisite:** Relay v0.1.0 General Availability  

---

## 1. Scope & Objective

This document isolates all future enhancements and post-MVP functionality from the frozen Relay `v0.1.0` release line. No functionality listed herein may be backported to `v0.1.x` unless required as a backward-compatible security or bug fix.

---

## 2. Planned v0.2 Candidates

### 2.1 Enhanced Sandboxing & OS Isolation
* **macOS Endpoint Security / Network Extension Sandbox:** Explore kernel-level network filtering on macOS using Network Extension / Endpoint Security APIs to achieve parity with Linux Network Namespaces.
* **Windows AppContainer Isolation:** Explore Windows AppContainer / WFP (Windows Filtering Platform) isolation for external MCP subprocesses.

### 2.2 Extended Native Connectors
* **Kubernetes Connector:** Native in-process connector for Kubernetes API interactions (pod logs, deployments, namespace-scoped RBAC).
* **AWS / Cloud Provider SDK Connectors:** Direct IAM-governed native cloud connectors with temporary STS role assumption.
* **Redis / Key-Value Connector:** Native in-process Redis / Memcached connector with command-level ACL governance.

### 2.3 Credential Broker Integrations
* **HashiCorp Vault Plugin:** Dynamic leasing backend connecting Relay to enterprise HashiCorp Vault clusters.
* **AWS Secrets Manager & GCP Secret Manager:** Direct remote KMS/secret synchronization backends.
* **Hardware HSM / PKCS#11 Signing:** Direct support for hardware security modules (YubiKey, Nitrokey, Cloud HSM) for DSSE receipt signing.

### 2.4 Enterprise & Policy Management UX
* **Visual Policy Simulator:** Interactive policy dry-run and validation CLI / web UI for Cedar policy authoring.
* **Remote Ledger Sync / Log Ingestion:** Optional non-blocking ledger replication to enterprise SIEM platforms (Splunk, Datadog, AWS CloudWatch).
* **Multi-Node Ledger Federation:** Cryptographic proofs for federated multi-agent execution topologies.
