## 1. What is Relay?

Relay is a local-first security control plane interposed between untrusted AI agents and Model Context Protocol (MCP) tools. Relay enforces a hard security boundary:

> **Authority + Credential Isolation + Evidence**  
> *Under complete prompt-injection compromise of the agent, the agent cannot obtain ambient credentials, bypass Cedar authorization, escape network sandbox boundaries, or mutate state without generating tamper-evident cryptographic evidence.*

---

## 2. What is Included in v0.1.0

1. **Deterministic Cedar Policy Engine:** Fast (<2ms) declarative authorization evaluating strongly-typed PARC policies.
2. **Ambient Credential Elimination:** Target credentials never enter the agent process, environment, or memory.
3. **Just-in-Time Credential Broker:** Single-action microsecond credential leasing with RAII memory zeroization.
4. **Governed Native Connectors:** In-process governance for Filesystem, PostgreSQL, and GitHub APIs.
5. **Interactive Out-of-Band Approvals:** Direct `/dev/tty` operator prompts cryptographically bound to `ActionHash`.
6. **RFC 9598 DSSE Action Receipts:** Cryptographically signed in-toto attestations with Ed25519 digital signatures.
7. **SQLite Hash-Chain Ledger:** Append-only cryptographic ledger with database write-once immutability triggers.
8. **External MCP Egress Proxy & Sandboxing:** Linux Network Namespace isolation (`CLONE_NEWNET`), anti-SSRF filters (SI-022), and action-bound session tokens.
9. **Offline Verification Suite:** `relay verify` for mathematical proof of ledger and signature validity.
10. **Canonical Golden Demo:** One-command reproducible demonstration (`./scripts/demo/run.sh`).

---

## 3. What is Not Included (Boundaries & Non-Goals)

- **Host Kernel / Root Compromise:** Relay relies on standard OS kernel isolation; a compromised root kernel is out of scope.
- **macOS / Windows Raw Socket Isolation:** macOS and Windows operate in Managed Cooperative Proxy Mode (Linux NetNS provides kernel-enforced raw socket blocking).
- **Multi-Node Distributed Consensus:** v0.1.0 is a local-first single-host binary. Multi-node Byzantine consensus is deferred to future enterprise extensions.
- **Asynchronous Long-Running Tasks:** MCP 2024-11-05 request-response framing is supported; background detached daemons are out of scope.

## 4. Installation & Quick Start

```bash
# Non-root safe installation
curl -fsSL https://raw.githubusercontent.com/relay-security/relay/main/install.sh | bash

# Diagnose health and sandbox status
relay doctor

# Run the canonical Golden Demo
git clone https://github.com/relay-security/relay.git
cd relay
./scripts/demo/run.sh
```
